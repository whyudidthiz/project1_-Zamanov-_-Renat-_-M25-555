# Лабиринт сокровищ (Treasure Labyrinth)

Консольная игра на Python. Управление осуществляется с помощью команд.

## Особенности

- Исследование комнат с уникальными описаниями.
- Сбор и использование предметов (факел, меч, ключ и др.).
- Загадки с возможностью ввода ответов.
- Случайные события (ловушки, находки).
- Инвентарь и отслеживание шагов.
- Победа при открытии сундука с сокровищем.

## Установка

### Требования
- Python 3.10 или выше
- Poetry 

### Шаги

1. Клонируйте репозиторий:
    ```bash
      git clone https://github.com/whyudithiz/project1_-Zamanov-_-Renat-_-M25-555.git
      cd project1_-Zamanov-_-Renat-_-M25-555
2. Установите зависимости через Poetry:
    ```bash
      poetry install
3. Активируйте виртуальное окружение и запустите игру
    ```bash
      make install
      make package-install
      make build
      make project

## Команды

go <направление> / north, south, east, west – переместиться в соседнюю комнату

look – осмотреть текущую комнату

inventory / inv – показать содержимое инвентаря

take <предмет> – подобрать предмет из комнаты

use <предмет> – использовать предмет из инвентаря

solve – попытаться решить загадку в комнате

help – показать справку

quit – выйти из игры
